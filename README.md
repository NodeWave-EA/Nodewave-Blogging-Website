# NodeWave Blogging Website

A modern, high-performance blog built with **Nuxt 4**, **Nuxt Content v3**, **Nuxt UI**, and **Tailwind CSS v4**.

---

## Tech Stack

| Layer             | Technology                                                                             |
| :---------------- | :------------------------------------------------------------------------------------- |
| **Framework**     | [Nuxt 4](https://nuxt.com/) (Vue 3.5+, TypeScript)                                     |
| **UI & Styling**  | [Nuxt UI](https://ui.nuxt.com/) & [Tailwind CSS v4](https://tailwindcss.com/)          |
| **Content & CMS** | [Nuxt Content v3](https://content.nuxt.com/) & [Nuxt Studio](https://studio.nuxt.com/) |
| **SEO**           | [Nuxt SEO](https://nuxtseo.com/)                                                       |
| **Utilities**     | [VueUse](https://vueuse.org/)                                                          |

---
